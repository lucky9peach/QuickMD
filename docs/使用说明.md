# QuickMD 使用说明

双击这个文件——如果它是用 **QuickMD** 打开的，说明默认打开方式已经设置成功。🎉

## 它有多快

- 原生 Swift，程序本体仅 **~200KB**，无 Electron、无臃肿依赖
- 启动即预热渲染引擎，打开文件只是一次 JS 调用（约 **10~20ms**）
- 底部状态条会实时显示：`文件大小 · 字数 · 渲染毫秒数`

## 功能

| 功能 | 操作 |
|------|------|
| 打开文件 | 双击 `.md` / 拖文件到窗口 / `⌘O` |
| 重新载入 | `⌘R`（文件被外部修改后也会**自动重载**） |
| 导出 PDF | 工具栏 / `⌘E` |
| 导出超长图 PNG | 工具栏 / `⇧⌘E`（超长文档自动分片拼接） |
| 导出 HTML | 工具栏 / `⌘H`（独立单文件，发给别人直接看） |
| 字号 | `⌘+` / `⌘-` / `⌘0` |
| 主题 | `⌘T`（跟随系统 / 浅色 / 深色） |
| 多窗口 | 每个文件独立窗口，互不干扰 |

## 排版

- 正文 16px、行高 1.8，标题/段落/列表自动留白
- 代码块、表格、引用、任务列表均有舒适样式
- 相对路径图片可直接显示（与 md 同目录的截图、assets 都行）
- 外链点击后用默认浏览器打开

## 文件位置

- App：`/Applications/QuickMD.app`（系统级，双击默认用它打开）
- 源码：`QuickMD/`（`Sources/QuickMD.swift` 单文件，`Resources/` 放模板/样式/解析器）
- 改完样式或代码后，进 `QuickMD/` 跑 `./build.sh` 即可重新编译安装
